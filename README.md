# Интеграция веб-сервисами REST

## Описание
Изучила принципы интеграции информационных систем с использованием REST API. На примере системы онлайн-записи в барбершоп проработала взаимодействие между клиентской и серверной частями, определила методы обмена данными, структуру запросов и ответов, правила сопоставления данных и требования к обработке ошибок.

## Полученные навыки
- Понимание REST API (изучила принципы REST, клиент-серверную архитектуру и особенности взаимодействия систем по HTTP)
- Проектирование интеграций (определяла сценарии взаимодействия систем и необходимость передачи справочных данных)
- Работа с HTTP-методами (выбирала GET, POST, PUT и DELETE с учетом выполняемой операции, безопасности и идемпотентности)
- Описание структуры данных и маппинг (определяла параметры запросов и ответов, типы данных, обязательность полей и соответствие атрибутов между системами)
- Проработка обработки ошибок (описывала коды состояния, сообщения об ошибках и проверки входных данных, включая недоступность внешних систем и некорректные значения)

## Этапы проекта
1. Разбор основных понятий, принципов архитектуры REST, форматов данных и HTTP-методов.
2. Доработка сценариев регистрации клиента и формирование расписания мастера с учетом участников, приложений и интеграционных взаимодействий.
3. Определение запросов, URL-пути, параметров, тела запроса, успешных и ошибочных ответов.
4. Составление спецификации элементов сообщений и выполнение маппинга между данными систем и передаваемыми сообщениями.
5. Определение проверки данных, условия возникновения ошибок, коды, сообщения и критичность проблем.

## Заключение
Проект помог разобраться в принципах взаимодействия информационных систем через REST API и закрепить навыки системного аналитика по описанию интеграционных сценариев, контрактов API, структур данных, маппинга и обработки ошибок.
